application-build identifiers. It does not bundle Apple executables, frameworks,
SDK headers, source-code extracts, decompiler output, disassembly dumps, or
copied application instruction sequences. The single root commit contains only

grant. It grants no rights in Apple software or other third-party material.

affiliation or endorsement is claimed.

## Local reproduction

Interested readers can run the portable model, native public-API reproduction,
and live terminal probe on their own systems. Those paths use project code,
public APIs, and terminal queries, without requiring disassembly.

Additional binary inspection is optional. Applicable software terms and law
must be considered separately; this project does not grant permission to
inspect software, bypass protections, or redistribute software extracts.
Asking readers to generate results locally does not create an automatic
copyright exception or waive applicable terms. Keep software extracts local,
and contribute original explanations, numeric facts, and measurement methods
rather than Apple software content.

This document describes the distribution policy; it is not a legal opinion.
